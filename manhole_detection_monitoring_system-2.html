About the Project

Making manhole monitoring smarter, safer and more responsive.

The Manhole Detection and Monitoring System uses an ESP32 as the main IoT controller and combines multiple sensors and communication modules. The system can monitor manhole conditions, water level and environmental parameters, while providing local indicators and remote communication for improved safety and awareness.
